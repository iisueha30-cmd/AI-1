핵심 구성요소

👁️

인지 (Perception)

환경과 입력을 받아들이는 부분. 텍스트, API 응답, 센서 데이터 등을 인식합니다.

🧠

추론 & 계획

무엇을 할지 판단하는 부분. LLM의 사고 과정과 계획 수립이 여기에 해당합니다.

💾

기억 (Memory)

이전 대화, 상태, 작업 이력을 저장합니다. 단기 기억과 장기 기억으로 나뉩니다.

🛠️

행동 (Action / Tools)

실제로 실행하는 부분. 도구 호출, API 실행, 파일 조작 등이 포함됩니다.

에이전트 유형

유형특징
반응형 (Reactive)규칙 기반으로 즉각 반응하며, 별도의 기억을 갖지 않습니다.
숙고형 (Deliberative)목표를 세우고 계획을 수립한 뒤 목표 지향적으로 행동합니다.
하이브리드반응형과 숙고형을 함께 사용해 빠른 대응과 계획을 모두 지원합니다.
LLM 기반 에이전트언어모델이 추론과 도구 호출을 주도하는 최근 트렌드입니다.

활용 사례

💻

코딩 어시스턴트

코드 작성, 리뷰, 리팩터링을 자동으로 도와줍니다.

💬

고객 응대 챗봇

문의에 답하고 필요하면 담당자에게 연결합니다.

📄

리서치 & 요약

문서나 자료를 조사하고 핵심만 정리해줍니다.

🤖

업무 자동화

반복적인 업무 프로세스를 RPA와 결합해 자동화합니다.
